For [self-hosting](/docs/getting-started/self-hosting). Values are read from the **repo root** —
`.env`, then `.env.local` overriding it.

## Required

Without these, nothing starts.

| Variable              | Notes                                                                |
| --------------------- | -------------------------------------------------------------------- |
| `DATABASE_URL`        | Postgres connection string. Neon is what the project targets         |
| `NEXT_PUBLIC_APP_URL` | Public origin. Used for OAuth callbacks, email links and invite URLs |
| `BETTER_AUTH_SECRET`  | Minimum 32 characters. **Needed at build time as well as runtime**   |

```bash
openssl rand -base64 32   # BETTER_AUTH_SECRET
```

<Callout type="warn" title="The build-time requirement is the usual surprise">
  `next build` runs with `NODE_ENV=production`, and the auth library refuses to
  construct with its default secret in production. Any build importing auth —
  all of them — fails without this. Set it in your CI or Vercel build
  environment too.
</Callout>

## Authentication

| Variable                                    | Effect when unset                   |
| ------------------------------------------- | ----------------------------------- |
| `BETTER_AUTH_URL`                           | Falls back to `NEXT_PUBLIC_APP_URL` |
| `GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET` | No Google sign-in button            |
| `GITHUB_CLIENT_ID` / `GITHUB_CLIENT_SECRET` | No GitHub sign-in button            |

Providers are only registered when **both** halves are present — a half-configured provider would be
a button that fails after the redirect with an opaque error from the provider.

Redirect URIs: `<origin>/api/auth/callback/google` and `<origin>/api/auth/callback/github`.

## Email

| Variable                | Effect when unset                                            |
| ----------------------- | ------------------------------------------------------------ |
| `RESEND_API_KEY`        | Sending fails closed with a clear error                      |
| `RESEND_WEBHOOK_SECRET` | The webhook rejects events, so delivery status never updates |
| `EMAIL_FROM`            | Defaults to `Invoicey <invoices@mail.invoicey.ditrich.me>`   |
| `CRON_SECRET`           | Overdue reminders never fire                                 |

Setup: [sending email](/docs/guides/sending-email#deployment-setup).

## Automation

| Variable                    | Effect when unset                                                                 |
| --------------------------- | --------------------------------------------------------------------------------- |
| `MCP_API_KEY`               | No deployment-wide ops key. Personal keys from **Settings → API keys** still work |
| `EVE_API_KEY`               | HTTP access to `/eve/v1/*` falls back to `MCP_API_KEY`                            |
| `AI_GATEWAY_API_KEY`        | The Slack agent has no model. Vercel OIDC can substitute                          |
| `INVOICEY_AI_MODEL`         | Defaults to `openai/gpt-4o-mini`                                                  |
| `INVOICEY_PRESETS_PATH`     | Falls back to `~/.invoicey/presets.json`                                          |
| `INVOICEY_PRESETS_BACKEND`  | Postgres when `DATABASE_URL` is set; set to `file` to force JSON                  |
| `INVOICEY_DEMO_ISSUER_JSON` | A built-in demo issuer is used when no preset is given                            |

See [API keys](/docs/integrations/api-keys).

## Storage

| Variable             | Effect when unset                                                                                                       |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| `UPLOADTHING_TOKEN`  | No uploads. Issuer asset fields still accept pasted URLs, and invoice PDFs are regenerated on demand rather than stored |
| `UPLOADTHING_APP_ID` | Optional companion                                                                                                      |

## Deployment

| Variable                             | Notes                                                                                   |
| ------------------------------------ | --------------------------------------------------------------------------------------- |
| `NEXT_PUBLIC_APP_STAGE`              | `development` · `production` · `staging` · `beta` · `alpha`. Drives environment banners |
| `DATABASE_URL_UNPOOLED`              | Direct connection for migrations. Optional locally                                      |
| `INVOICEY_DEFAULT_WORKSPACE_ID`      | Workspace used by machine identities that carry no session — MCP, Slack, cron           |
| `VERCEL_USE_EXPERIMENTAL_FRAMEWORKS` | Set to `1` at **build** time or the Slack agent's routes are never generated            |

## Fail-closed by default

Optional variables never mean "open". Each unset key disables its path rather than leaving it
unauthenticated:

- No `RESEND_WEBHOOK_SECRET` → the webhook rejects all events.
- No `CRON_SECRET` → the reminder endpoint refuses.
- No `MCP_API_KEY` → the shared ops key simply does not exist. `/api/mcp` still authenticates
  personal keys, and still rejects everything else.

A deployment missing a key is inert, not exposed.

## Local template

`.env.example` at the repo root is the maintained list. Copy it and fill in what you need:

```bash
cp .env.example .env.local
```
