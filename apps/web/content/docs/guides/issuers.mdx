An **issuer** is a business you invoice from. A workspace can hold several, each with its own bank
account, numbering and branding.

## Creating one

Open [My businesses](/issuers), then **New business**. On your first sign-in, the welcome flow
also helps you create the first business. Enter the IČO and look it up in
[ARES](/docs/guides/clients#ares-lookup), then review the legal name, address and DIČ it returns.
Check your contact details and bank account yourself; a registry lookup cannot supply everything.

ARES cannot tell you everything, so these are yours to supply:

<Steps>

<Step>

### Bank account

Enter the Czech domestic account number. Invoicey suggests its IBAN as you type; check both against
your bank before saving. If you edit the IBAN yourself, the form preserves that edit rather than
silently replacing it with a new suggestion.

The supported formats are:

| Field          | Format                     | Example                    |
| -------------- | -------------------------- | -------------------------- |
| Account number | `[prefix-]number/bankCode` | `19-2000145399/0800`       |
| IBAN           | `CZ` + 22 digits           | `CZ6508000000192000145399` |
| BIC            | Optional, 8 or 11 chars    | `GIBACZPX`                 |

The account number appears on the PDF; the IBAN powers the [payment QR](/docs/outputs/payment-qr).
Invoicey checks the IBAN checksum and that it matches the domestic account number. A mismatch must
be corrected before saving. These checks do not verify account ownership. Connecting a bank for
[payment matching](/docs/integrations/bank-connections) is a separate, optional step.

</Step>

<Step>

### VAT payer flag

Whether you charge DPH. Turning it **off** forces every line on every invoice to 0 % and replaces the
VAT recap on the PDF with _Nejsem plátce DPH_. See [Czech VAT](/docs/concepts/czech-vat).

</Step>

<Step>

### Contact email

Required. It is saved with the issuer details on an issued invoice and becomes the reply address
when that invoice is emailed. Check it before issuing: changing the business contact later does not
rewrite older invoices. See [email delivery](/docs/guides/sending-email#sender-and-replies).

</Step>

<Step>

### Registry note

The optional _zápis v obchodním rejstříku_ line:

> Společnost zapsaná v obchodním rejstříku vedeném Krajským soudem v Brně, oddíl C, vložka 12345.

Sole traders generally use:

> Fyzická osoba zapsaná v živnostenském rejstříku.

Use the wording from your registry entry.

</Step>

<Step>

### Numbering scheme

Each document type has its own scheme. The standard invoice default `{YYYY}{####}` gives
`20260001` for the first invoice of 2026; proforma, advance and credit-note defaults include their
own prefixes. Full token list and reset behaviour
in [numbering](/docs/concepts/numbering).

</Step>

</Steps>

## Logos, stamps and signatures

Three optional images placed on the PDF:

| Asset           | Formats   | Max size |
| --------------- | --------- | -------- |
| Logo            | PNG, JPEG | 1 MB     |
| Stamp (razítko) | PNG, JPEG | 1 MB     |
| Signature       | PNG, JPEG | 1 MB     |

Open the business’s **Assets** section and choose an image from your device. On a computer, you
can also drag it onto the upload area. SVG, WebP and HEIC are not accepted; export the image as
PNG or JPEG first. A transparent PNG works well for a logo, stamp or signature.

Review the preview, then save the section. Uploading the file alone does not save the business
settings. Use the image’s remove control to clear it, or choose another image to replace it.

Replacing an asset preserves its old URL so issued-invoice [snapshots](/docs/concepts/snapshots)
continue to render correctly.

## Email settings

Per issuer, used at send time:

| Setting                 | Default                           |
| ----------------------- | --------------------------------- |
| Default subject         | `Faktura {number} — {issuerName}` |
| Default cover text      | Invoice cover message, editable   |
| Attach ISDOC by default | on                                |
| Display name template   | `{issuerName} via Invoicey`       |
| Overdue reminders       | off                               |
| Reminder interval       | 7 days                            |
| Payment-received email  | off                               |

Email settings are read **when you send**, so changes also apply when resending an older invoice.
Review custom subject and cover text when using English documents: saved template wording is not
automatically translated. See [email delivery](/docs/guides/sending-email) for recipient review,
delivery status and blocked addresses.

## Editing an issuer

Open a business from [My businesses](/issuers). Settings are split into five sections:

| Section   | What to change                                                     |
| --------- | ------------------------------------------------------------------ |
| Identity  | Legal and contact details, address and VAT-payer status            |
| Bank      | Domestic account, IBAN and optional BIC                            |
| Assets    | Logo, stamp and signature uploads                                  |
| Numbering | Separate number schemes for each document type                     |
| Email     | Subject, cover text, attachment preferences and automated messages |

**Save each section before moving to another.** A change in one section does not save unsaved edits
in the others. You can add optional branding and email preferences after completing the required
identity and bank details.

Edits apply to **future** invoices only. Already-issued invoices hold frozen copies and will not
change — see [snapshots](/docs/concepts/snapshots).

Rebranding or switching banks is safe, but a correction does not rewrite an invoice already issued.

## Presets for automation

[MCP](/docs/integrations/mcp), [ChatGPT](/docs/integrations/chatgpt) and
[Slack](/docs/integrations/slack) use the connected workspace's issuer. Choose the default under
**My businesses**, then check it with `get_workspace` in MCP before drafting. If no default is
marked, the tools use the first saved business; explicitly setting the default keeps the choice clear.

`create_invoice` does not accept an issuer or preset ID. Saving an issuer preset does not change
the seller selected by that tool. If the connected workspace has no usable issuer, drafting stops
until you complete issuer setup. Changing the business registry affects future drafts; issued
invoices retain their frozen seller details.
