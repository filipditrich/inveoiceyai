An **issuer** is a business you invoice from. A workspace can hold several, each with its own bank
account, numbering and branding.

## Creating one

**Issuers → New.** Enter the IČO and Invoicey fills the legal name, address and DIČ from
[ARES](/docs/guides/clients#ares-lookup).

ARES cannot tell you everything, so these are yours to supply:

<Steps>

<Step>

### Bank account

Add the domestic account and IBAN:

| Field          | Format                     | Example                    |
| -------------- | -------------------------- | -------------------------- |
| Account number | `[prefix-]number/bankCode` | `19-2000145399/0800`       |
| IBAN           | `CZ` + 22 digits           | `CZ6508000000192000145399` |
| BIC            | Optional, 8 or 11 chars    | `GIBACZPX`                 |

The account number appears on the PDF; the IBAN powers the [payment QR](/docs/outputs/payment-qr).
Invoicey validates their formats, not whether they identify the same account.

</Step>

<Step>

### VAT payer flag

Whether you charge DPH. Turning it **off** forces every line on every invoice to 0 % and replaces the
VAT recap on the PDF with _Nejsem plátce DPH_. See [Czech VAT](/docs/concepts/czech-vat).

</Step>

<Step>

### Contact email

Required. It becomes the `Reply-To` on every invoice email sent for this issuer, so client replies
reach you rather than the sending domain.

</Step>

<Step>

### Registry note

The optional _zápis v obchodním rejstříku_ line:

> Společnost zapsaná v obchodním rejstříku vedeném Krajským soudem v Brně, oddíl C, vložka 12345.

Sole traders generally use:

> Fyzická osoba zapsaná v živnostenském rejstříku.

Use the wording from your registry entry.

</Step>

<Step>

### Numbering scheme

Per document type. The default `{YYYY}{####}` gives `20260001`. Full token list and reset behaviour
in [numbering](/docs/concepts/numbering).

</Step>

</Steps>

## Logos, stamps and signatures

Three optional images placed on the PDF:

| Asset           | Formats        | Max size |
| --------------- | -------------- | -------- |
| Logo            | PNG, JPEG, SVG | 1 MB     |
| Stamp (razítko) | PNG, JPEG      | 1 MB     |
| Signature       | PNG, JPEG      | 1 MB     |

Uploads go through Invoicey's file storage. Prefer PNG or JPEG — SVG is not rasterised reliably for
the PDF. Without an uploaded file you can still paste a publicly reachable image URL.

Replacing an asset preserves its old URL so issued-invoice [snapshots](/docs/concepts/snapshots)
continue to render correctly.

## Email settings

Per issuer, used at send time:

| Setting                 | Default                           |
| ----------------------- | --------------------------------- |
| Default subject         | `Faktura {number} — {issuerName}` |
| Default cover text      | —                                 |
| Attach ISDOC by default | on                                |
| Display name template   | `{issuerName} via Invoicey`       |
| Overdue reminders       | off                               |
| Reminder interval       | 7 days                            |
| Payment-received email  | off                               |

Email settings are read **when you send**, so changes also apply when resending an older invoice.

## Editing an issuer

Edits apply to **future** invoices only. Already-issued invoices hold frozen copies and will not
change — see [snapshots](/docs/concepts/snapshots).

Rebranding or switching banks is safe, but a correction does not rewrite an invoice already issued.

## Presets for automation

[MCP](/docs/integrations/mcp), [ChatGPT](/docs/integrations/chatgpt) and
[Slack](/docs/integrations/slack) use the connected workspace's issuer. Choose the default under
**My businesses**, then check it with `get_workspace` in MCP before drafting. If no default is
marked, the tools use the first saved business; explicitly setting the default keeps the choice clear.

`create_invoice` does not accept an issuer or preset ID. Saving an issuer preset does not change
the seller selected by that tool. If the connected workspace has no usable issuer, drafting stops
until you complete issuer setup. Changing the business registry affects future drafts; issued
invoices retain their frozen seller details.
