## The builder

**Invoices → New.**

Pick the issuer and the client, then add lines. Each line has a description, quantity, unit, unit
price and VAT rate. Totals recalculate as you type, grouped per rate.

Need a new client? Choose **Add manually** in the client section. The form opens over your invoice;
saving selects the client and keeps your line items, dates and other edits in place. Cancel returns
to the invoice without creating a client. You can also add a Czech business by IČO through ARES.

This works for new invoices and existing drafts. Adding a client does not save or issue the invoice:
choose **Save draft** when you want to persist the invoice changes.

For a new invoice, the browser can also keep a recovery copy in the current tab. That copy is not a
saved Invoicey draft. If storage is blocked or full, the editor explains that recovery is unavailable;
keep the page open and use **Save draft** before leaving. The browser restriction does not prevent
saving a valid draft to your workspace.

The header fields:

| Field           | Default                      | Notes                                                 |
| --------------- | ---------------------------- | ----------------------------------------------------- |
| Document type   | `invoice`                    | Also proforma, advance, credit note                   |
| Issue date      | Today                        |                                                       |
| Due date        | Issue date + 14 days         | Must not precede the issue date                       |
| DUZP            | Issue date                   | Required on invoices and credit notes. Can be earlier |
| VAT mode        | `regular`                    | Reverse charge and OSS are the alternatives           |
| Variable symbol | Digits of the invoice number | The payment reference your client quotes              |
| Notes           | —                            | Free text, max 2000 chars, printed on the PDF         |

A **credit note** additionally requires the number of the invoice it corrects.

Saving produces a [draft](/docs/concepts/statuses): no number, fully editable, not a tax document.
Drafts follow live edits to the issuer and client until you issue.

## From JSON

**Invoices → From JSON** validates and renders a complete payload. Use it to test the schema, debug
automation or handle a scripted one-off.

Validation runs as you type and points to the failing field.

Field reference: [invoice schema](/docs/reference/invoice-schema).

## From an assistant

Use [Invoicey in ChatGPT](/docs/integrations/chatgpt), the [web AI draft](/invoices/ai),
or another [MCP assistant](/docs/integrations/mcp) to describe the work instead of filling every field:

> Prepare a draft using my workspace issuer for 40 hours of consulting at 1,800 CZK per hour,
> plus 12,000 CZK for integration work. Ask me for the client, dates, VAT treatment, document
> language and any other missing details. Show me the draft before issuing it.

The connected-workspace tools use the issuer configured in Invoicey. Add your business and set
its default before drafting; passing an issuer preset does not select a different seller. The
assistant can look up the client, ask for missing facts and prepare a validated draft. Review the
result and any assumptions before issuing:

<Callout type="warn" title="Read what the assistant produced">
  Validation guarantees an invoice is *well-formed*, not that it is *correct*.
  The schema cannot detect that the model billed 40 hours when you worked 4, or
  picked 21 % where 12 % applied. Review the draft before issuing — issuing is
  the irreversible step, not creating.
</Callout>

## Templates

An **invoice template preset** can store reusable draft data for an MCP assistant. It is separate
from a recurring schedule and does not change the workspace issuer. The assistant must include the
confirmed invoice facts in its draft; `create_invoice` does not accept a template preset ID.

For a one-off repeat, use **Duplicate**. For scheduled drafts, use **Repeat** as described below.

## Recurring drafts

Open an invoice and choose **Repeat**, then name the schedule. Choose weekly, monthly, quarterly
or yearly recurrence. For non-weekly schedules the day picker offers the first, fifteenth or last
day of the month, plus the source invoice's day when applicable. Weekly schedules advance by seven days.

Invoicey creates a **draft**, using the current issuer and client details and the template's line
items and payment terms. It does not issue or email the invoice automatically. By default the first
scheduled run is after today. A daily scheduled job prepares due drafts; **Run now** creates one on demand.

Under **Invoices → Recurring** you can open the latest draft, pause or resume the schedule, skip the
next run, run it now or delete the recurring template. If its previous draft is still unissued,
Invoicey skips creating another. To change the saved lines or recurrence, create a replacement from
the desired invoice and pause or remove the old schedule; the list has no template editor.

## Duplicating

Duplicate any invoice to create a fresh draft. Invoicey copies its content but clears the number,
issue facts, payment and snapshots.
