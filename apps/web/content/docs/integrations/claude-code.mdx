Claude Code connects to MCP servers from the CLI, so the same tools available in
[Cursor](/docs/integrations/cursor) work here.

## Adding the server

The hosted endpoint, added for your user rather than one project:

```bash
claude mcp add --transport http --scope user invoicey https://your-host/api/mcp --header "Authorization: Bearer YOUR_API_KEY"
```

Or the local server against a repository checkout:

```bash
claude mcp add --scope user invoicey-local -- bun run --cwd /abs/path/to/inveoiceyai/apps/mcp src/stdio.ts
```

Verify:

```bash
claude mcp list
```

<Callout title="Prefer user scope for the hosted endpoint">
  `--scope project` writes to `.mcp.json` in the repository, which is checked in
  and shared. A bearer token does not belong there. User scope keeps it in your
  own config.
</Callout>

## Using it

Tools appear as `invoicey` tools in any session:

> Look up NFCtron in ARES, then draft an invoice from my "main" issuer preset for October
> consulting — 32 hours at 1 800 CZK. Due in 14 days.

And for follow-ups against the hosted endpoint:

> List unpaid invoices and tell me which are overdue.
>
> Mark 20260012 as paid and email the client a copy with the ISDOC attached.

Claude Code will ask before tools that send email or change payment state. Let it.

## Presets first

`create_invoice` needs an issuer preset, otherwise it falls back to a demo issuer that renders
correctly and is entirely fictional. Save one before your first real invoice — see
[presets](/docs/integrations/mcp#presets).

## What works where

|                              | Hosted `/api/mcp` | Local stdio                     |
| ---------------------------- | ----------------- | ------------------------------- |
| ARES lookup and search       | yes               | yes                             |
| Create and render an invoice | yes               | yes                             |
| Presets                      | yes               | file-backed                     |
| List, get, mark paid         | yes               | only with `DATABASE_URL`        |
| Send email                   | yes               | only with a database and Resend |

## Troubleshooting

<Accordions>

<Accordion title="Unauthorized on every call">
  The key was revoked, mistyped, or truncated when copied. Personal keys are
  shown once — if you are not certain you have it intact, create a new one under
  **Settings → API keys**. Test the endpoint directly with `curl` before
  debugging the client.
</Accordion>

<Accordion title="The server shows as failed">
  Run `claude mcp list` for status. For the local server, run its command by
  hand to see the startup error; a successful boot prints `[invoicey-mcp] stdio
  server ready`. Relative paths and `~` are not resolved — use absolute paths.
</Accordion>

<Accordion title="Only some tools are available">
  The database-backed tools are not registered when there is no database. Use
  the hosted endpoint, or set `DATABASE_URL` in the local server's environment.
</Accordion>

</Accordions>
