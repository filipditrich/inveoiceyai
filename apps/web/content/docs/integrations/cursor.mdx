Cursor speaks MCP natively, so Invoicey's tools appear alongside its own once configured.

## Configuration

MCP servers are configured in `mcp.json` — `~/.cursor/mcp.json` for every project, or
`.cursor/mcp.json` inside one project.

```json
{
  "mcpServers": {
    "invoicey": {
      "url": "https://invoicey.app/api/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY"
      }
    }
  }
}
```

Create the key under **[Workspace → API keys](/settings/workspace/api-keys)** — see [API keys](/docs/integrations/api-keys).

<Callout type="warn" title="Do not commit this file">
  A project-level `.cursor/mcp.json` containing a bearer token is a credential
  in your repository. Add it to `.gitignore`, or configure Invoicey globally in
  `~/.cursor/mcp.json` instead.
</Callout>

Then **Settings → MCP → Reload**, and confirm Invoicey is listed with its tools.

## Set up the workspace issuer

In Invoicey, add your business under **My businesses**, complete its identity, contact email and
bank details, and choose the default issuer. Connected-workspace invoice tools read that seller
server-side; they do not accept an issuer preset ID. A workspace without a usable issuer cannot
create a draft. See [issuer setup](/docs/guides/issuers).

Ask the assistant to call `get_workspace` first so you can check the connected workspace and issuer.

## Working with it

Cursor decides when to call tools, so plain description works:

> Look up IČO 27074358 and prepare a draft using my workspace issuer for 25 hours of development
> at 1,500 CZK per hour, due in 21 days. Ask for missing dates, VAT and document language. Do not issue it yet.

Check the client, seller, amounts, dates and assumptions before confirming issuance.

For follow-ups:

> Show me everything unpaid, oldest first.
>
> Mark invoice 20260007 paid as of yesterday.

## Troubleshooting

<Accordions>

<Accordion title="The server does not appear after reloading">
  Check the URL includes `/api/mcp`, the JSON is valid, and you reloaded MCP in
  Cursor settings.
</Accordion>

<Accordion title="Every call returns unauthorized">
The key was revoked, mistyped, or truncated when copied. Personal keys are shown once, so create a
fresh one under **[Workspace → API keys](/settings/workspace/api-keys)** if you are unsure. Verify with:

```bash
curl -X POST https://invoicey.app/api/mcp \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
```

</Accordion>

<Accordion title="create_invoice keeps failing validation">
  Nothing is silently defaulted, so a missing required field is an error rather
  than a guess. The usual culprits are `duzp`, a due date before the issue date,
  and a missing client DIČ under reverse charge. The error names the failing
  path — paste it back to the assistant and it will correct itself. See the
  [schema reference](/docs/reference/invoice-schema).
</Accordion>

</Accordions>
