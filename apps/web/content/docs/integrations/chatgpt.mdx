Invoicey connects your workspace to ChatGPT. Describe the work, review the invoice in an
interactive card, and decide when to issue or send it. The same invoice stays available in Invoicey.

## Start here

[Install Invoicey in ChatGPT](https://chatgpt.com/plugins/plugin_asdk_app_6ac15c60bad48191b03d0059a8f7561c).
The public plugin is available for users in Czechia. You need a ChatGPT account and an Invoicey
workspace. Developer mode, server URLs and API keys are not required.

1. Create an Invoicey workspace and add your default issuer, contact email, VAT settings and payment details.
2. Open the official listing above and choose **Install plugin**. Sign in to ChatGPT if prompted.
3. Choose **Connect**, sign in to Invoicey with Google or GitHub, and select your workspace.
4. Review the requested access and approve the connection.
5. In a new conversation, select **Invoicey** and ask: **“Show my recent invoices in Invoicey.”**
   This first check only reads data.

The [setup page](/chatgpt) provides these steps in Czech and English. The public plugin includes
both the connected invoice tools and the invoicing skill; no separate workflow package is needed.
If you previously installed a private development version, use the official listing for the public release.

### Desktop, web and mobile

Start with the public listing on ChatGPT web. Invoicey views adapt to phone screens, and the
consent flow has desktop and mobile-browser regression coverage. Native ChatGPT iOS/Android
behavior has not yet been validated. Availability of interactive views and composer invoice
mentions depends on the ChatGPT host; responsive views alone do not establish native mobile support.

## From a sentence to an invoice

> Prepare a draft for 12 hours of design at 1,500 CZK per hour. Use my workspace seller,
> look up the client's confirmed IČO, and ask me for any missing details. Show me the draft
> before issuing it.

Invoicey validates client details, dates, currency, document language and line items. The
assistant should ask for missing facts instead of inventing them. Review the recipient, amounts,
VAT, due date and assumptions. Ask for a correction or confirm issuance when ready.

The invoice view lets you:

- Search invoices by client or number and filter unpaid invoices.
- Review seller, recipient, items, taxes and totals.
- Issue a saved draft, send an invoice to a chosen email address, or record payment after confirmation.
- Open stored PDF and ISDOC documents or continue in the Invoicey web app.
- Attach an invoice to the current conversation without sending a new message.

In supporting hosts, type `@` and search Invoicey invoices to attach a reference. Only invoices in
the connected workspace are available. Issued invoices cannot be changed through the draft editor.

## Workspace and access

OAuth access stays bound to the workspace you approved, even if you switch workspaces in the
Invoicey website. Connect again to approve a different workspace. Permissions are checked on
every request: removing a member or changing their role changes what the connection can do.

To disconnect, open **Workspace settings → Integrations → ChatGPT & MCP** in Invoicey and
remove the application's connection. Remove it in ChatGPT as well if you no longer want it listed.
Signing out/revoking the originating Invoicey session also invalidates that connection.

## Troubleshooting

- **Sign-in repeats:** reconnect and approve access again. Do not paste API keys into the conversation.
- **No issuer:** add a default issuer in Invoicey before asking for a draft.
- **Missing action:** check your workspace role, plan and approved write access.
- **No interactive card:** your host may support tools only. The assistant can still use the MCP tools;
  open Invoicey to inspect the document.
- **Wrong workspace:** reconnect and select the intended workspace on the consent screen.

Historical invoice import, recurring schedules and bank connection setup remain in the web app.
See [MCP](/docs/integrations/mcp) for other assistants and personal-key clients.
