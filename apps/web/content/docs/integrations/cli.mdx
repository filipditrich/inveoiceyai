Invoicey CLI is an operator cockpit for the same workspace the web app, MCP, and
Slack already share. It is not a second Invoicey — looks, members, bank connect,
and bulk import stay on the website.

## Install

The public installer detects macOS or Linux and the current architecture,
downloads the matching standalone binary, verifies it against the published
SHA-256 checksum, and puts it in `~/.invoicey/bin`:

```bash
curl -fsSL https://invoicey.ditrich.me/install | bash
```

Open a **new** terminal, or add the install directory to the current shell:

```bash
export PATH="$HOME/.invoicey/bin:$PATH"
invoicey --version
invoicey login
```

Set `INVOICEY_INSTALL_DIR` to choose another destination. Set
`INVOICEY_VERSION` to install a specific release instead of the latest one.

### Build from the repository

Contributors can compile and install the current checkout with Bun:

```bash
bun install
bun run invoicey:install
```

The installer:

1. Builds `apps/cli/src/bin.ts` → `apps/cli/dist/invoicey`
2. Copies that file to `~/.invoicey/bin/invoicey`
3. Appends `export PATH="$HOME/.invoicey/bin:$PATH"` to your shell rc
   (`.zshrc`, `.bashrc`, or fish `config.fish`) if that PATH is not already there

Re-run `bun run invoicey:install` after pulling CLI source changes.

To run from source without compiling:

```bash
bun run --filter=@invoicey/cli start
```

## Login

Create a personal key under **Settings → API keys** — see [API keys](/docs/integrations/api-keys).

```bash
invoicey login
```

Paste the key, keep the default API URL (`https://invoicey.ditrich.me`) unless
you are hitting a local `bun dev`. The key is stored in `~/.invoicey/cli.json`
(mode `0600`). You can also set `INVOICEY_API_KEY` and optional
`INVOICEY_API_URL`.

`login` calls `POST /api/companion` with `{ "op": "me" }`. A bad key is `401`.
If something in front of the API returns HTML (a redirect to sign-in, a
challenge page), the CLI prints the content-type and a body snippet — it does
not swallow that as a generic “unexpected response (200)”.

## Daily use

```bash
invoicey                  # interactive home
invoicey status
invoicey invoices --unpaid
invoicey invoices show 20260012
invoicey invoices issue 20260012
invoicey invoices send 20260012
invoicey invoices new --ico 27082440 --desc "October consulting" --qty 32 --price 1800 --vat 21
invoicey clients add 27082440
invoicey payments
invoicey ares NFCtron
```

Invoice refs are an issued **number** or a UUID. Irreversible actions confirm
in a TTY unless you pass `--yes`. `--json` prints the companion payload.

<Callout title="Same validation as every other surface">
  Drafts still go through `InvoiceSchema`. The CLI cannot invent an issuer —
  create injects the workspace default, the same way MCP does.
</Callout>

## Files on disk

| Path                       | What                   |
| -------------------------- | ---------------------- |
| `~/.invoicey/bin/invoicey` | Compiled command       |
| `~/.invoicey/cli.json`     | API URL + PAT (`0600`) |

Logout removes `cli.json`. It does not uninstall the binary. Delete
`~/.invoicey/bin/invoicey` and the PATH line in your shell rc if you want it
gone.
