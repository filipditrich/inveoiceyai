# Invoicey audit

This folder contains a browser-led, authenticated audit of the current Invoicey user experience.

- [Current user flows and UX map](./invoicey-current-user-flow.md) — the main review document.
- [Seamless UX pass specification](../specs/seamless-ux-pass.md) — the maintained implementation decisions derived from this historical audit.
- [Seamless UX browser evidence](./improvements/README.md) — focused screenshots captured after the implementation pass.
- [`screenshots/`](./screenshots/) — screenshots captured during the walkthrough.
- [`dom/`](./dom/) — route-level DOM snapshots used as evidence for labels, controls, and states.

The audit is intentionally descriptive. It records what the product did on 24 August 2026; it does not propose implementation changes.
